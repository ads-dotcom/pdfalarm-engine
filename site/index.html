A FEW DETAILS

Know what you’re building with.

Is PDFAlarm Engine free to use?

Yes. The engine is MIT licensed. The bundled Noto fonts have their own SIL Open Font License. Your hosting or infrastructure provider may charge for your own deployment.

Does it support every language?

Font support depends on the font bytes you provide. The examples include Noto Sans and test Turkish, Latin, Greek and Cyrillic text. Arabic shaping, CJK fonts, emoji and right-to-left layout are outside the initial release’s verified scope. Missing glyphs produce an explicit error.

Can I overlay an existing PDF?

Yes. Pass its bytes as basePdf and use matching template page dimensions. See the overlay example and guide. Rotated and encrypted input PDFs are not supported in v0.1.

Is this an HTML-to-PDF service?

The initial engine uses JSON drawing templates. It does not render HTML/CSS or include a billing or customer management system.

How can I contribute?

Try the examples, report reproducible problems and propose improvements through GitHub issues. Read the contribution guide before opening a pull request.
