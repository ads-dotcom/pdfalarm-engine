A PDF in a few lines.

A typed JSON template, your data and optional font bytes. The engine returns real PDF bytes you can save, download or return from your own service.

Install and generate

Use Node.js 22 or newer. The first release is an installable GitHub tarball; npm registry publishing is not configured. 

npm install https://github.com/ads-dotcom/pdfalarm-engine/releases/download/v0.1.0/pdfalarm-engine-0.1.0.tgz

Save this as example.mjs next to your package.json, then run node example.mjs: 

import { readFile, writeFile } from 'node:fs/promises';
import { renderPdf } from 'pdfalarm-engine';

const fontBytes = new Uint8Array(await readFile(new URL(
  './node_modules/pdfalarm-engine/assets/fonts/NotoSans-Regular.ttf',
  import.meta.url
)));

const { bytes } = await renderPdf({
  template: {
    version: 1,
    pages: [{
      width: 595.28, height: 841.89,
      elements: [{
        type: 'TEXT', x: 40, y: 60,
        width: 515, height: 70,
        font: 'NotoSans', fontSize: 24,
        text: 'Hello, {{person.name}}'
      }]
    }]
  },
  data: { person: { name: 'İpek Yılmaz' } },
  fonts: { NotoSans: fontBytes }
});
await writeFile('hello.pdf', bytes);

Template basics

Templates use version: 1 and a pages array. Each page has width, height and elements. Dimensions are PDF points (72 points per inch), measured from the top left. Unknown fields and out-of-page boxes are rejected.

Element Main fields
TEXT text or dataField, font, fontSize, align, lineHeight, formatter
RECTANGLE / LINE fill/stroke or color, strokeWidth
QR_CODE text or dataField, errorCorrection, quietZone (minimum 4)
BARCODE text or dataField, barcodeType: code128/ean13, showText
IMAGE asset key, aspect-preserving contain fitting
TABLE dataPath, columns, font, padding, topMargin, bottomMargin

Each element includes x, y, width and height. Bindings accept {person.name} or {{person.name}}. A dataField binds an entire value. Conditions use strict comparisons; formatted number, currency and date fields accept explicit locales.

Browse working templates: invoice, label, certificate. The exact runtime schema and TypeScript types are in the source.

Fonts and language support

Pass a map of names to font bytes and use the same name in an element’s font. Noto Sans regular and bold are included in the package and distributed under the SIL Open Font License. The examples verify Turkish, Latin, Greek and Cyrillic text.

Helvetica, Courier and other standard PDF fonts work without extra font bytes, but do not cover every language. Missing glyphs produce an error. RTL, Arabic shaping, CJK and emoji are outside the first release’s verified scope.

Tables that continue

A TABLE must be the final element on its template page. Column widths must sum to its width. The table’s height defines its available first-page region. Additional rows continue on new pages with repeated headers and top/bottom margins. Text wraps inside cells; rows too tall for a page fail explicitly.

Use continuationElements on the template page for continuation headers and footers, positioned outside the table region. 

{
  "type": "TABLE",
  "x": 40, "y": 100, "width": 515, "height": 660,
  "font": "NotoSans", "dataPath": "items",
  "columns": [
    { "header": "Description", "path": "name", "width": 365 },
    { "header": "Quantity", "path": "qty", "width": 150 }
  ]
}

Assets and existing PDFs

Pass PNG/JPEG bytes through assets. The engine does not fetch arbitrary image URLs. Optional resolveAsset(key, signal) callbacks have a deadline; your application must bound reads and control sources.

Pass trusted PDF bytes as basePdf. Template dimensions must match the original pages. Rotated and encrypted input pages are unsupported. Overlaying is not PDF sanitization or signing. 

await renderPdf({
  template, data, fonts,
  basePdf: existingPdfBytes,
  assets: { logo: { bytes: pngBytes, format: 'png' } }
});

Explicit errors and sensible limits

Catch PdfAlarmError and inspect its code: INVALID_TEMPLATE, INVALID_DATA, LIMIT_EXCEEDED, FONT_NOT_FOUND, UNSUPPORTED_GLYPH, TEXT_OVERFLOW, ASSET_ERROR, INVALID_PDF or INVALID_BARCODE.

Defaults: 50 pages, 2,000 rows, 1 MB each for template/data, 5 MB per asset, 20 MB output, 200,000 text characters and a five-second resolver deadline. Configure limits for your workload. Public rendering services need their own authentication, request limits and isolation.

Your own deployment

Clone the public repository, run npm ci and npm run check. npm run dev starts the website locally. Deploy it to your own Cloudflare account with npm run deploy after configuring credentials and choosing a Worker name. The browser demo needs no database or bucket.

For Node.js, browser and self-hosted Worker integration, read the API guide. See security notes, contributing and third-party licenses.
