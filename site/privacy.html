Your documents stay with you.

The playground

The demo parses your JSON, generates PDF bytes and previews them inside your browser. Template and document data are not submitted to a rendering server. Downloaded PDFs are created locally. Refreshing the page resets the playground; it does not save your input to our database or local storage.

Website requests

The site, fonts, PDF viewer and sample files are served by Cloudflare. Cloudflare receives ordinary website request information such as IP addresses and request headers. Hosting logs and platform processing may occur. We do not add advertising trackers, third-party analytics, account registration or application cookies.

External links

GitHub links take you to GitHub, where its own privacy policy applies. Issues and pull requests are public: use fictional data and never post customer documents or credentials.

Contact and security

The maintainer account is ads-dotcom. General questions can be raised in repository issues. Report security vulnerabilities privately through the repository’s Security tab.
