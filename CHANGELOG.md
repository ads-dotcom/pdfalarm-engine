# Changelog

## 0.1.0 — 2026-09-13

First independent open-source release of the PDFAlarm template engine.

- Typed versioned JSON schema and runtime input validation.
- Embedded font selection with explicit missing-glyph errors.
- Text wrapping, flowing tables, repeated headers and continuation decorations.
- QR quiet zones, Code 128/EAN-13 barcodes and explicit PNG/JPEG assets.
- Existing PDF overlays and configurable resource limits.
- Browser playground, Node.js/Worker guides and four generated PDF examples.
- Real PDF regression tests and automated validation/deployment workflows.

The previous application was private. This repository begins with the extraction
and hardening work; its history does not claim prior public maintenance activity.
