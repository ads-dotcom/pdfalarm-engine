# Roadmap

## Released in 0.1.0

Standalone rendering, validated templates, tested Turkish fonts, wrapping tables,
barcodes, QR, assets, overlays and an open browser demo.

## Next maintenance priorities

- Add more regression fixtures from reproducible external reports.
- Improve table styling and document layout diagnostics.
- Investigate tagged/accessible PDF generation before claiming PDF accessibility.
- Evaluate right-to-left shaping with real language fixtures and suitable fonts.
- Add a legacy template conversion utility if users need it.
- Evaluate npm registry publishing when maintainer credentials are configured.

No promised dates or invented usage figures. Improvements depend on actual user
needs and maintainer capacity. Report concrete needs through GitHub issues.
